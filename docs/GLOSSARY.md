# Glossary of Terms — GeoForge

> **Document:** `docs/GLOSSARY.md`  
> **Status:** Canonical Verified Glossary  
> **Target Version:** GeoForge v1.0.0 (SIH 2026 / NTRO Edition)

---

- **AGL (Above Ground Level):** The operational altitude of a drone relative to the terrain directly beneath it. Used in flight capture guidance (typically recommended 30–50m AGL).
- **Camera Pose:** The 6-DoF position $\mathbf{C} = [x, y, z]^T$ and orientation (rotation matrix $\mathbf{R}$) of a camera in 3D world space at the instant a frame was exposed.
- **COLMAP:** Open-source Structure-from-Motion (SfM) and Multi-View Stereo (MVS) software suite powering GeoForge's core photogrammetric pipeline.
- **CORS (Cross-Origin Resource Sharing):** HTTP protocol mechanism that allows the browser-based client (`http://localhost:3000`) to access the backend API (`http://127.0.0.1:8000`).
- **Dense Point Cloud:** A high-density collection of millions of 3D spatial coordinates with associated RGB colors and surface normals, generated by dense stereo depth fusion (`colmap/dense/fused.ply`).
- **Feature Keypoint & Descriptor:** Invariant local visual patterns (e.g., SIFT) detected in an image, described numerically to enable matching across viewpoint and scale changes.
- **Georeferencing:** The transformation that maps local photogrammetric camera coordinates to real-world geographic coordinates (e.g., WGS84, UTM). Not currently implemented in GeoForge.
- **GLB (glTF Binary):** Binary container format for glTF 2.0 that packages 3D mesh geometry, vertex normals, UV texture coordinates, and PBR materials into a single self-contained file.
- **Ground Truth:** High-precision, independently surveyed geospatial measurements or LiDAR scans used to evaluate reconstruction error.
- **Job ID:** A unique UUID4 identifier allocated by FastAPI to track an asynchronous video upload and its reconstruction workspace (`backend/temp/{job_id}/`).
- **Laplacian Variance:** Second-order spatial derivative filter $\text{Var}(\nabla^2 I)$ used in `backend/frame_filtering.py` to evaluate high-frequency image edge sharpness and discard motion blur.
- **Mesh:** Surface representation composed of 3D vertices, connecting edges, and triangular planar faces.
- **Multi-View Stereo (MVS):** Dense photogrammetric pipeline stage (PatchMatch stereo and depth fusion) that estimates dense surface geometry from registered images.
- **Normal Vector:** A unit vector $\mathbf{n} = [n_x, n_y, n_z]^T$ perpendicular to a 3D surface, critical for accurate Poisson meshing and realistic WebGL lighting.
- **Orthomosaic:** A geometrically corrected, uniform-scale composite aerial photograph generated from orthorectified images; not generated by the prototype pipeline.
- **Photogrammetry:** The science and technology of obtaining reliable 3D measurements and geometric models from intersecting optical rays recorded in overlapping 2D photographs.
- **PLY (Polygon File Format):** Standard binary or ASCII 3D file format used by COLMAP and Open3D to store point clouds (`fused.ply`) and surface meshes (`poisson_mesh.ply`).
- **Redundancy Filter:** Frame difference algorithm (`cv2.absdiff`) that discards consecutive video frames with insufficient parallax ($\Delta < 5.0$), bounded by a 50% safety floor.
- **Screened Poisson Surface Reconstruction:** An implicit surface meshing algorithm in Open3D that solves Poisson's equation $\Delta \chi = \nabla \cdot \mathbf{V}$ over an adaptive octree (depth 11) to create watertight triangle meshes.
- **Single-Model SfM:** Running COLMAP mapper with `--Mapper.multiple_models 0` to enforce a single coherent coordinate system rather than multiple disjoint sub-models.
- **Sparse Reconstruction:** Initial photogrammetric bundle adjustment producing camera poses and triangulated 3D tie points (`colmap/sparse/0/`).
- **Structure-from-Motion (SfM):** The computational process of simultaneously estimating camera internal calibrations, camera poses, and 3D scene structure from overlapping 2D images.
- **Three.js:** JavaScript WebGL 3D rendering library used by `ThreeDViewer.tsx` to render interactive models in the browser.
- **Trimesh:** Python geometry library used by `backend/convert_to_glb.py` to merge meshes, bind Pillow PBR diffuse textures, and export binary GLB assets.
- **UV Mapping:** 2D texture coordinate parameterization $(u, v) \in [0, 1]^2$ mapping planar image pixels from a texture atlas to 3D mesh polygon surfaces.
